# KENTO-DEN WEB版

長々工房の2D格闘ゲーム「KENTO-DEN」のWEB公開版です。`index.html` 1ファイルで動きます（音・画像も埋め込み済み、フォントのみGoogle Fontsから読み込み）。

## 遊び方
- タイトルで「対戦」「トーナメント」「トレーニング」を選べます。
- トーナメントは自分のキャラを選んで、CPU7人と勝ち抜き戦。優勝するとラスボス戦も自分で戦います。
- 大会のあと、キャラから要望が出ます。要望はランダム（必殺技の出の速さ・隙・威力、与えるダメージを3〜10%ほど）で、規定の範囲なら承認されてキャラに反映されます。
- 変更はブラウザごと（プレイヤーごと）に保存されます。ページ上部の「強化リセット」で最初の状態に戻せます。
- AIは使っていません。

## 公開（GitHub Pages）
このフォルダをリポジトリのルート（または `docs/`）に置き、Settings → Pages で公開元に指定してください。
